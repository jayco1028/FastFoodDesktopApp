# Privacy Policy

_Last updated: [DATE]_

## Overview

This application ("the App") is a desktop point-of-sale / self-order kiosk simulation built with Python and Tkinter. This Privacy Policy explains what data the App does and does not collect.

## Unofficial Project Notice

This App is an independent, unofficial project created for educational/demonstration purposes. It is **not affiliated with, endorsed by, or sponsored by Jollibee Foods Corporation** or any of its subsidiaries or brands. Any product names, menu items, or branding referenced are used solely for illustrative purposes.

## Data Collection

The App does **not** collect, transmit, or store any personal data. Specifically:

- **No internet connection required.** The App runs entirely offline and does not send data to any server.
- **No account creation or login.** The App does not require or collect names, emails, phone numbers, or payment information.
- **No persistent storage of orders.** Cart and order data (items selected, order totals, order IDs) exist only in memory while the App is running and are cleared when the App is closed.
- **No analytics or tracking.** The App does not use cookies, telemetry, or any third-party analytics services.
- **No payment processing.** Any "payment" or "checkout" flow in the App is simulated for demonstration purposes only and does not process real financial transactions.

## Local Image Files

The App may read image files from a local folder (e.g. `image/`) bundled with the application, used solely to render menu item icons. These files are not collected, modified, or transmitted anywhere.

## Changes to This Policy

If this project evolves to include real data collection, networking, or payment processing, this Privacy Policy will be updated accordingly before such features are released.
